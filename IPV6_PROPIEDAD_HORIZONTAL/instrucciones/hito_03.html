Hito 3 (3/10): Configuración de Enrutamiento IPv6 y Subinterfaces 802.1Q en R1

1. Objetivo del Hito

Habilitar el reenvío global de paquetes IPv6 (ipv6 unicast-routing) en R1 y configurar las subinterfaces 802.1Q (Gi0/0.10 a Gi0/0.50) junto con las interfaces hacia SRV-DNS (Gi0/1) y Cloud-PT (Gi0/2).

2. Contexto Técnico

Por defecto, los routers Cisco IOS no reenvían paquetes IPv6 ni envían mensajes ICMPv6 Router Advertisement (RA) hasta que se ejecuta el comando global ipv6 unicast-routing. Además, el uso de una dirección Link-Local uniforme (FE80::1) en cada subinterfaz facilita la identificación del gateway predeterminado en todos los departamentos.

3. Dispositivos Involucrados

Router principal R1 (Cisco 2911).

4. Comandos Necesarios

R1(config)# ipv6 unicast-routing
R1(config)# interface GigabitEthernet0/0
R1(config-if)# no ip address
R1(config-if)# no shutdown
!
R1(config)# interface GigabitEthernet0/0.10
R1(config-subif)# encapsulation dot1Q 10
R1(config-subif)# ipv6 address FE80::1 link-local
R1(config-subif)# ipv6 address 2001:DB8:ACAD:10::1/64
R1(config-subif)# ipv6 enable
!
R1(config)# interface GigabitEthernet0/0.20
R1(config-subif)# encapsulation dot1Q 20
R1(config-subif)# ipv6 address FE80::1 link-local
R1(config-subif)# ipv6 address 2001:DB8:ACAD:20::1/64
R1(config-subif)# ipv6 enable
!
R1(config)# interface GigabitEthernet0/0.30
R1(config-subif)# encapsulation dot1Q 30
R1(config-subif)# ipv6 address FE80::1 link-local
R1(config-subif)# ipv6 address 2001:DB8:ACAD:30::1/64
R1(config-subif)# ipv6 enable
!
R1(config)# interface GigabitEthernet0/0.40
R1(config-subif)# encapsulation dot1Q 40
R1(config-subif)# ipv6 address FE80::1 link-local
R1(config-subif)# ipv6 address 2001:DB8:ACAD:40::1/64
R1(config-subif)# ipv6 enable
!
R1(config)# interface GigabitEthernet0/0.50
R1(config-subif)# encapsulation dot1Q 50
R1(config-subif)# ipv6 address FE80::1 link-local
R1(config-subif)# ipv6 address 2001:DB8:ACAD:50::1/64
R1(config-subif)# ipv6 enable
!
R1(config)# interface GigabitEthernet0/1
R1(config-if)# ipv6 address FE80::1 link-local
R1(config-if)# ipv6 address 2001:DB8:ACAD:99::1/64
R1(config-if)# ipv6 enable
R1(config-if)# no shutdown
!
R1(config)# interface GigabitEthernet0/2
R1(config-if)# ipv6 address FE80::1 link-local
R1(config-if)# ipv6 address 2001:DB8:ACAD:FF::1/64
R1(config-if)# ipv6 enable
R1(config-if)# no shutdown

5. Procedimiento Paso a Paso

  1. Active ipv6 unicast-routing en modo de configuración global en R1.
  2. Encienda la interfaz física GigabitEthernet0/0 con no shutdown.
  3. Configure las cinco subinterfaces Gi0/0.10 a Gi0/0.50 con su respectiva etiqueta encapsulation dot1Q y dirección IPv6 GUA y Link-Local.
  4. Configure GigabitEthernet0/1 (red de servicios 2001:DB8:ACAD:99::1/64) y GigabitEthernet0/2 (WAN 2001:DB8:ACAD:FF::1/64).

6. Resultado Esperado

La tabla de enrutamiento IPv6 de R1 muestra las 7 redes directamente conectadas (C) y sus direcciones locales (L).

7. Evidencia Solicitada al Estudiante

Salida de show ipv6 interface brief y show ipv6 route en R1.

8. Criterio de Evaluación

Verificación automática de IPv6 Unicast Routing = 1, estado de puertos en R1 y líneas de subinterfaces en RUNNINGCONFIG.
