Hito 7 (7/10): Configuración del Servidor DNS (SRV-DNS) y Registros AAAA

1. Objetivo del Hito

Configurar el direccionamiento IPv6 estático del servidor de servicios internos SRV-DNS (2001:DB8:ACAD:99::10/64) y habilitar el servicio DNS con registros de tipo AAAA para la resolución de nombres en el dominio propiedadhorizontal.local.

2. Contexto Técnico

Los departamentos con DHCPv6 Stateless (VLAN 20 y 40) y DHCPv6 Stateful (VLAN 30) reciben automáticamente la dirección 2001:DB8:ACAD:99::10 como servidor DNS IPv6. Para que los residentes puedan resolver nombres de servicios del edificio, SRV-DNS debe publicar registros AAAA (IPv6 host address records, RFC 3596).

Nombre de Dominio (FQDN)TipoDirección IPv6 Destino
dns.propiedadhorizontal.localAAAA2001:DB8:ACAD:99::10
portal.propiedadhorizontal.localAAAA2001:DB8:ACAD:99::10
administracion.propiedadhorizontal.localAAAA2001:DB8:ACAD:99::10
r1.propiedadhorizontal.localAAAA2001:DB8:ACAD:99::1

3. Dispositivos Involucrados

Servidor SRV-DNS (Server-PT) y Router R1 (interfaz GigabitEthernet0/1).

4. Comandos y Parámetros Necesarios

! En SRV-DNS (Desktop -> IP Configuration):
IPv6 Address      : 2001:DB8:ACAD:99::10 / 64
Link-Local Address: FE80::99:10
IPv6 Gateway      : 2001:DB8:ACAD:99::1
IPv6 DNS Server   : 2001:DB8:ACAD:99::10

5. Procedimiento Paso a Paso

  1. Abra SRV-DNS → Desktop → IP Configuration y asigne la dirección IPv6 estática 2001:DB8:ACAD:99::10/64, gateway 2001:DB8:ACAD:99::1 y DNS 2001:DB8:ACAD:99::10.
  2. Vaya a la pestaña Services → DNS, active el servicio (DNS Service = On) y agregue los registros AAAA Record de la tabla superior.
  3. En los puntos de acceso AP-D1 a AP-D5, verifique que sus puertos estén encendidos y con los SSID Depto1_IPv6 a Depto5_IPv6.

6. Resultado Esperado

Desde PC-D2, PC-D3 y PC-D4 es posible hacer ping 2001:DB8:ACAD:99::10 y resolver portal.propiedadhorizontal.local.

7. Evidencia Solicitada al Estudiante

Captura de la tabla de registros AAAA en SRV-DNS y prueba de ping portal.propiedadhorizontal.local desde PC-D3.

8. Criterio de Evaluación

Verificación automática de IPv6 Enable = 1, Default Gateway IPv6 = 2001:DB8:ACAD:99::1 y DNS Enable = 1 en SRV-DNS.
