Hito 6 (6/10): Configuración de DHCPv6 Stateful en Departamento 3 (VLAN 30)

1. Objetivo del Hito

Configurar DHCPv6 Stateful (con estado) en el router R1 para el Departamento 3 (VLAN 30), de manera que el servidor DHCPv6 del router administre y asigne tanto la dirección IPv6 Global Unicast dentro de 2001:DB8:ACAD:30::/64 como el servidor DNS y el nombre de dominio al host PC-D3.

2. Contexto Técnico

En DHCPv6 Stateful, el anuncio RA en la subinterfaz Gi0/0.30 activa el flag M=1 (ipv6 nd managed-config-flag). Esto indica al cliente que debe solicitar su dirección IPv6 completa a un servidor DHCPv6 mediante el intercambio de 4 mensajes (SARR: Solicit, Advertise, Request, Reply), registrando el arrendamiento (binding) en la tabla de estado del router.

3. Dispositivos Involucrados

Router R1 (pool DEPT3_STATEFUL y subinterfaz Gi0/0.30) y terminal PC-D3.

4. Comandos Necesarios

R1(config)# ipv6 dhcp pool DEPT3_STATEFUL
R1(config-dhcpv6)# address prefix 2001:DB8:ACAD:30::/64 lifetime 172800 86400
R1(config-dhcpv6)# dns-server 2001:DB8:ACAD:99::10
R1(config-dhcpv6)# domain-name propiedadhorizontal.local
R1(config-dhcpv6)# exit
!
R1(config)# interface GigabitEthernet0/0.30
R1(config-subif)# ipv6 nd managed-config-flag
R1(config-subif)# ipv6 dhcp server DEPT3_STATEFUL

5. Procedimiento Paso a Paso

  1. Cree el pool DEPT3_STATEFUL en R1 e incluya la directiva address prefix 2001:DB8:ACAD:30::/64 lifetime 172800 86400, junto con dns-server 2001:DB8:ACAD:99::10 y domain-name propiedadhorizontal.local.
  2. En la subinterfaz GigabitEthernet0/0.30, active ipv6 nd managed-config-flag y vincule el pool mediante ipv6 dhcp server DEPT3_STATEFUL.
  3. En PC-D3 → Desktop → IP Configuration, active el modo dinámico IPv6 (DHCP / Auto Config) y verifique la concesión de dirección y DNS.

6. Resultado Esperado

PC-D3 recibe una dirección IPv6 administrada en el prefijo 2001:DB8:ACAD:30::/64, gateway FE80::1 y servidor DNS 2001:DB8:ACAD:99::10, y R1 registra clientes activos en el pool DEPT3_STATEFUL.

7. Evidencia Solicitada al Estudiante

Salida de show ipv6 dhcp pool y show ipv6 dhcp binding en R1, más ipv6config /all en PC-D3.

8. Criterio de Evaluación

Verificación automática del pool DEPT3_STATEFUL con address prefix 2001:DB8:ACAD:30::/64, el comando ipv6 nd managed-config-flag en Gi0/0.30 y la activación IPv6 en PC-D3.
